## How to contribute changes

If you have changes (e.g., bug fix, new features) that you'd like to contribute to the WISE Community, please create a pull request on the corresponding WISE-Community GitHub repository.

- [WISE-API](https://github.com/WISE-Community/WISE-API)
- [WISE Client](https://github.com/WISE-Community/WISE-Client)
- [WISE Docker Development](https://github.com/WISE-Community/WISE-Docker-Dev)
- [WISE Docker Server](https://github.com/WISE-Community/WISE-Docker-Server)

The development team at Berkeley will review it and work with you to merge it into the develop branch.
