# Introduction

This page allows administrators to batch create student accounts.

# How to Create Users

From the Admin homepage, click on the "Batch Create Users" link. The page will have a link to download a sample CSV file. You can also download this sample CSV file here: [batch-users-sample.csv](batch-users-sample.csv)

The CSV file will contain fields for creating new student accounts, like first name, last name, username, password, etc. Each row will create a new student account. Edit this file to create as many students as needed.

After uploading the CSV file, the system will create the student accounts.
